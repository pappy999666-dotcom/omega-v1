Current Problems

1.
Status Design no longer renders.

Instead of

(Status Design)
↓
Link Preview

Native Preview
↓
Raw Link

meaning the preview builder bypasses the StatusDesign renderer completely.

StatusDesign must ALWAYS execute first.

The preview system must enrich it, never replace it.



2.

• title only
• no thumbnail

4.
