The current implementation is completely wrong.

Current behaviour:

Everyone is mentioned in one paragraph.

Example:

@user @user @user @user @user

This is NOT what .mtag should do.

Requirements:

.mtag is the VISIBLE mention command.

It should:

✓ Mention every group member.
✓ Display one member per line.
✓ Never place everyone on one line.
✓ Support thousands of members.
✓ Support attached text.
✓ Support quoted messages.
✓ Support media.

Example:

│
│ ☩ @Alpha
│ ☩ @Nova

│ ☩ @Charmaine
│

The mention list must be generated dynamically.

No commas.

No inline mentions.

No paragraph formatting.
